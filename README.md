# 星际守护者

《星际守护者》是一款以高速空战、流派构筑和首领对抗为核心的浏览器飞机大战。

## 背景介绍

深空航道失去回应后，守护舰队派出最后一架仍能作战的战机进入星渊。敌军、失控兵器与未知信号不断从航道深处出现，一道神秘黑影则始终潜伏在战场边缘，等待夺走每一份被击败的力量。

玩家会在持续推进中收集强化、改变战斗方式，并逐步接近信号背后的真相。普通战役不会提前公开接下来的威胁，异常回波、突然出现的敌人和战场变化需要玩家亲自发现。

## 六大流派

- 力量流派：强调正面火力、暴击成长与处决续航，适合稳定压制。

- 敏捷流派：以高速移动和散射弹幕穿梭战场，将暴击潜力转化为攻击与机动。

- 防御流派：依靠重甲、生命恢复和大口径火力稳步推进，容错率更高。

- 吸血流派：持续命中敌人即可修复舰体，擅长在高压弹幕中维持战线。

- 吞噬流派：通过连续击杀不断进化，让战机在单局内越战越强。

- 撞击流派：关闭常规机炮，以舰体冲撞和生命成长作为主要武器，适合贴身破阵。

## 普通战役九战流程

普通战役先清理小兵，再自然切入 Boss。界面不会显示触发 Boss 还差多少分，也没有剧情弹窗打断操作。

1. 裂渊泰坦。
2. 第一次追逐黑影：黑影强度 116.7%，累计造成其最大生命 50% 伤害后向上逃逸。
3. 镜像猎手：强度 133.3%。
4. 第二次追逐黑影：强度 141.7%，累计造成 75% 伤害后逃逸。
5. 技能篡夺者：强度 150.0%。
6. 第三次追逐黑影：强度 158.3%，累计造成 87.5% 伤害后逃逸。
7. 三 Boss 不完全体同场：每个模板为原属性的 66.7%，全部击破后连续升级 3 次。
8. 完全体黑影：会召唤小兵；剩余 12.5% 生命时爆炸并显露原型。
9. 黑暗魔神飞机：会召唤小兵；基础战斗数值为调整前的 66.7%，击破后战役结束。

完全体黑影爆炸后，玩家最大生命上限压至 3000，所有回血机制与技能效果乘 0.5。

## 敏捷流派 G 键专属

G 键为各流派共用键位，但技能逻辑完全独立：力量为龙息喷火，敏捷为影步突刺，撞击为全速冲锋，其余流派用于释放已装备的首领权柄。

### 影步突刺

沿准星方向突进，射程上限为地图竖直长度的 60%（768px），固定 400ms 完成，距离越远速度越快。鼠标超出射程时沿同方向截断到边缘。突进期间无敌，并对整条轨迹做扫掠判定，途经敌人全部受击。

| 等级 | 伤害倍率 | 扫掠宽度 | 冷却 |
| --- | ---: | ---: | ---: |
| Lv.1 | 110% | 56 | 30s |
| Lv.2 | 140% | 68 | 25s |
| Lv.3 | 170% | 80 | 20s |

每命中一个敌人恢复 2% 最大生命，单次突刺最多累计 5 次。击杀时额外增加 3 点本局生命上限。

### 影分身

与本体保持在同一水平线并列作战，优先攻击当前绝对血量最少的敌人，不受距离限制。数量上限 4 个，攻击上限为本体 100%，血量上限为本体 40%；达到上限后继续升级只缩短召唤间隔。

| 等级 | 数量 | 血量 | 攻击 | 召唤间隔 |
| --- | ---: | ---: | ---: | ---: |
| Lv.1 | 1 | 1 点血 | 25% | 30s |
| Lv.2 | 2 | 本体 10% | 50% | 25s |
| Lv.3 | 3 | 本体 25% | 75% | 20s |
| Lv.4+ | 4 | 本体 40% | 100% | 15s |

每次召唤只补充 1 个分身。Lv.1 的 1 点血意味着受到任何伤害都会立刻消散；更高等级按本体当前最大生命动态换算，本体生命成长或被压制时分身血量按百分比同步迁移。分身没有免伤和特殊减免，撞击敌人时按敌人真实撞击伤害扣血。

## 本次更新内容

- 修复影步突刺的位置插值缺陷：原实现的进度值恒为 0.5，战机瞬移到起终点中间即卡住。
- 修复影步突刺的命中标记从不清除的问题，此前第二次及之后的突刺完全无法造成伤害。
- 命中判定改为线段扫掠，高速穿过敌人时不再漏判；新增沿轨迹的金色光带、战机残影与终点冲击环。
- 影分身移除套在本体身上的三层光晕、描边与旋转外环，此前视觉上会被误认为护盾。
- 影分身改为优先攻击血量最少的目标（原实现为血量最高），站位对齐本体水平线并取消垂直抖动。
- 影分身撞击改为按敌人真实伤害扣血，此前无视血量直接消散，导致血量成长毫无意义。
- G 键改为按流派显式分派，修复敏捷流派未解锁突刺时误触发撞击流派技能提示的问题。
- 模式选择界面点击模式或难度后不再跳回页面顶部。
- 存档写入增加失败捕获与提示，避免浏览器隐私模式或配额耗尽时进度静默丢失。
- 敏捷流派暴击效果转移速系数调整为 0.3。
- 开启未使用变量检查，清理 3 个无调用点的函数与 14 个孤立 CSS 类，产物 CSS 体积减少约 9%。
- 新增 Vite 插件在文件保存时自动清除 BOM，并接入构建与测试流程。
