# 星际守护者

霓虹科幻风网页飞机大战：宽屏纵版战场、局内三选一 Roguelite 构筑、完整 Boss 战役、双人互伤、永久成长与涂装商店。当前版本为 `v0.5.1`。

## 启动

```bash
npm install
npm run dev
```

## 验证

```bash
npm run test
npm run build
```

## 操作

- 键盘：WASD / 方向键移动，按住 Space 开火。
- 主动技能：`1` 激光切割、`2` 导弹齐射、`3` 无人机过载、`Q` EMP 一键清屏、`E` 星核超载。
- 辅助技能：`F` 相位闪避、`R` 纳米修复、`X` 一键投降、`Esc` 暂停；撞击流派按 `E` 发动破阵冲刺，未取得首领权柄前按 `G` 启动全速推进。
- 双人模式：P1 使用 WASD / Space / `1 2 3 Q E`；P2 使用方向键 / Enter / `J K L`。双方子弹、导弹与 EMP 可以互相造成爆炸伤害。
- 鼠标或触屏：仅用于拖动战机移动；战斗技能全部绑定键盘。

### 流派专属机制

- 力量：初始暴击率 `11.7%`、暴击伤害倍率 `140%`；暴击完成击杀时回复 `5.8%` 最大生命，并增加 `2` 最大生命。
- 敏捷：自身不会暴击。暴击率每 `1%` 转换为 `2%` 攻击收益，攻击收益再按全局 `2/3` 规则结算；暴击效果每 `1%` 转换为 `1%` 移速。初始虚拟暴击率 `11.7%`、虚拟暴击效果 `140%`，因此初始攻击转换池为 `23.3%`、实际攻击增益约 `15.6%`，移动速度转换倍率为 `240%`；与流派速度相乘后为战机基础速度的 `336%`。击杀精英增加 `5%` 最大生命，每累计获得 `100` 最大生命回复 `9.3%` 已损生命。
- 防御：每次击杀回复 `2.3%` 最大生命；普通承伤 `69.4%`，爆炸叠乘后的总承伤约 `28.9%`。
- 吸血：每次命中回复 `3.5%` 已损生命，单次最低回复 `0.15`；普通承伤 `92.5%`。
- 吞噬：每次击杀使最大生命增加 `2%`，并回复 `1.2%` 最大生命，可在单局中持续成长。
- 撞击：永久关闭基础机炮和暴击。普通敌人接触冷却 `300ms`，Boss 接触冷却 `325ms`，受伤保护 `500ms`；每 `5` 秒回复 `5.8%` 最大生命。撞杀敌机吸收其最大生命的 `5%`，撞击完成 Boss 最后一击增加 `300` 最大生命。相对开局每新增 `500` 最大生命，当前攻击提高 `20%`，同步强化普通撞击、Boss 撞击和破阵冲刺。最大生命超过 `1000` 后，受到的 Boss 伤害再降低 `25%`；Boss 固定百分比攻击因此由 `12.5%` 最大生命降为 `9.4%`。破阵冲刺距离 `330`，基础冷却 `4.8` 秒，对 Boss 造成其最大生命的 `3.5%`，普通接触撞击造成 `2%`。

## 永久成长

- 机体和战斗流派分层选择：四种机体可搭配力量、敏捷、防御、吸血、吞噬、撞击六大流派。
- 全部流派的基础生命、攻击、速度、射速、暴击、拾取与回血统一提高 `1/6`；受到伤害和爆炸伤害倍率统一降低 `1/6`，技能冷却恢复各流派原始倍率，战机体型保持原样。
- 力量流派初始拥有 11.7% 暴击率和 140% 暴击效果；局内每次升级继续成长，暴击处决回复 5.8% 最大生命并增加 2 点生命上限。
- 敏捷流派不会暴击：暴击率按 1% → 2% 攻击力转换，暴击效果按 1% → 1% 移速转换；攻击收益继续按全局规则以原数值的三分之二结算。每轮随机使用扇形、弧线、螺旋、散射、交叉或圆环弹道，击杀精英使生命上限 +5%。本局每累计获得 100 点最大生命，会回复当前已损生命的 9.3%。
- 撞击流派永久关闭基础机炮，不会生成普通子弹，也不会获得无人机或会射出机炮弹的镜像僚机；仍可获得极光、导弹、电弧、旋刃等特殊武装，临时弹幕会转换为极光或导弹。
- 撞击流派拥有独立升级池：磁轨破城撞角、矢量冲锋引擎、动能偏转装甲、撞击再生核心、残骸吞噬器、动能震荡波和战场回收磁场。普通接触冷却为 300ms、Boss 接触冷却为 325ms、受伤保护为 500ms；基础撞击可直接击毁普通侦察机，对精英敌机额外造成 25% 伤害。每累计新增 500 最大生命，当前攻击力提高 20%，该成长会同步强化小兵撞击、Boss 基础 2% 撞击和破阵冲刺。
- 撞击杀死小兵时，最大生命增加该单位最大生命的 5%；由撞击完成 Boss 最后一击固定增加 300 最大生命。被动再生调整为每 5 秒回复 5.8% 最大生命。
- 撞击流派最大生命超过 1000 时，受到的 Boss 直接伤害、百分比伤害和黑暗持续伤害统一降低四分之一。
- 撞击流派按 `E` 发动破阵冲刺：沿当前方向瞬间贯穿 330 像素路径；`1/2/3` 禁用，`Q` 仍为 EMP 清屏。取得三神权柄后，`G` 改为释放持续 7 秒、冷却 40 秒的首领能力。
- 航途中会随机出现临时技能核心，可获得 12 秒歼灭超频、棱镜散射或奇点花火；精英敌机也有概率掉落。
- 击落普通敌机、精英敌机和 Boss 都会掉落星核币，奖励随关卡难度提高。
- 机库商店支持生命、火力、引擎、装甲、代币回收等有上限的永久加点。战场代币与经验拾取统一使用金色机械外圈、青蓝星核的专属图标，避免与绿色回血十字混淆。
- 敌人与 Boss 会获得玩家永久加点收益的 20%，避免后期战斗失去压力。
- 四套涂装可使用星核币购买并即时装备。

## 三种游戏模式

- 普通战役：小怪推进后依次挑战两名阶段 Boss，第三名为黑暗魔神最终 Boss；击破最终 Boss 后胜利结算并结束。
- 深空无尽：小怪和 Boss 无限循环。每次 Boss 死亡立即把本段代币写入仓库，下一轮清兵分数间隔按 Boss 阶级显著增长。
- 无限 Boss：不自然生成任何小怪。Boss 死亡后进入支援与跨流派强化选择，随后下一名 Boss 直接跃迁。
- 普通、困难、噩梦三个威胁等级继续控制敌军生命、精英概率、突变与奖励。

## 战斗平衡与保存

- 所有攻击类增益系数统一降低三分之一，只保留原来的 `2/3`；永久火力、火控核心、射速、暴击成长、流派增伤、临时强化、支援成长和武器等级成长均已同步。
- 所有玩家可见数值统一四舍五入：整数不显示小数位，非整数最多保留一位小数，避免浮点精度尾数进入升级说明和 HUD。
- “适者进化”每 12 次击杀提供的增伤降低三分之一，并设置 45% 单局总增伤上限。
- 非撞击流派的 `1/2/3` 主动技能基础伤害减半：激光 45、导弹 44、无人机过载 23，再乘当前机体面板。
- 模式、难度、双人类型、每日登录、仓库代币与永久成长全部写入 `localStorage`。刷新、关闭或重新开始时，尚未结算的局内代币会自动回收到仓库。
- 每日登录为 7 天循环：第 1 天 80 星核币，之后每天增加 30；漏签后从第 1 天重新计算，同一天不能重复领取。

## 首领与敌群

- 无尽模式拥有逐轮增长的清兵阶段，达到新分数阈值后触发首领，击败后继续飞行。
- 首领按裂渊泰坦、镜像猎手、技能篡夺者循环出现；每位首领都有带清晰预警与安全缺口的独立弹幕，并会在后续循环进入精英形态，获得金色力场、更多生命、更快攻势和更高奖励。
- 镜像猎手复制玩家机体并强化生命；技能篡夺者会临时封锁玩家主动技能并反过来使用。
- 每次击败首领会依次进入“逆航支援”与“跨流派进化”两个选择界面。逆航支援包括贯穿轰炸、引力减速、冻结全场、短暂无敌、纳米维修和猎杀扫荡，支援机均从屏幕下方向上掠过。
- 跨流派进化可自由选取力量、敏捷、防御、吸血、吞噬与通用技能。
- “镜像僚机”会复制当前战机，以本体约 50% 的尺寸和作战性能协同开火。
- 玩家最大生命超过 1000 时，首领的每次有效攻击固定造成最大生命的 12.5%。
- 所有流派的最大生命每跨过 1000 点，小兵基础伤害提高 20%；小兵每次有效伤害至少造成玩家最大生命的 5%，Boss、友军和环境伤害不套用该规则。
- 侦察、拦截、强袭、压制、布雷、炮艇、轰炸和送死补给机组成八类混合敌群；所有敌机均使用独立透明 PNG 机体素材并统一以机头朝下迎战玩家。
- 强袭机使用三联扇射，压制机在脉冲封锁与追踪弹之间随机切换，布雷机制造带安全缺口的爆炸雷幕；它们的强度位于普通战机与重型炮艇之间。
- 八类敌机都可随机生成精英形态：每种精英机都有独立黑金装甲 PNG，体型、生命、攻击和奖励全面强化；普通炮艇与精英炮艇也使用不同机体图片。
- Boss 整体生命提高 22%，攻击顺序改为随机抽取，第三阶段还会随机叠加追踪弹幕。
- 非撞击流派撞击普通敌机时直接摧毁目标并承受对应伤害，精英仅损失 25% 生命；撞击 Boss 固定造成 75 伤害。

在 URL 后添加 `?debug=1` 可显示调试面板；战斗中按 `B` 直接进入 Boss。

## 高性能生产构建包

当前游戏默认使用高性能渲染配置：优先独立显卡、像素对齐、精简星尘和粒子数量，并复用引擎尾焰对象；设置中可关闭“高性能模式”切换至更密集的电影级特效。生命值在计算与界面中统一四舍五入为整数。

构建时仍会生成 `星际守护者-高性能生产构建包.zip`，压缩包同时包含已经编译好的静态版与完整源码构建环境：

- 面向现代浏览器的 ES2022 输出。
- JavaScript/CSS 使用 esbuild 压缩，关闭 source map。
- Phaser 引擎独立分包并支持长期缓存。
- 解压后可运行 `node 启动游戏.mjs`，无需额外下载静态服务器依赖。
- 源码构建版使用 `npm ci`、`npm run build` 和 `npm run verify:release` 完成可复现编译与校验。
