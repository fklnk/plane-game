# 星渊突击

霓虹科幻风网页飞机大战：宽屏纵版战场、局内三选一 Roguelite 构筑、三首领无限轮换、双人模式、永久成长与涂装商店。

## 启动

```bash
npm install
npm run dev
```

## 验证

```bash
npm run test
npm run build
```

## 操作

- 键盘：WASD / 方向键移动，按住 Space 开火。
- 主动技能：`1` 激光切割、`2` 导弹齐射、`3` 无人机过载、`Q` EMP 一键清屏、`E` 星核超载。
- 辅助技能：`F` 相位闪避、`R` 纳米修复、`X` 一键投降、`Esc` 暂停；轮椅流派可按 `G` 启动全速冲锋。
- 双人模式：P1 使用 WASD / Space / `1 2 3 Q E`；P2 使用方向键 / Enter / `J K L`。
- 鼠标或触屏：仅用于拖动战机移动；战斗技能全部绑定键盘。

## 永久成长

- 机体和战斗流派分层选择：四种机体可搭配力量、敏捷、防御、吸血、吞噬、轮椅六大流派。
- 力量流派初始拥有 10% 暴击率和 120% 暴击效果；局内每次升级继续成长，暴击处决回复 5% 最大生命并增加 2 点生命上限。
- 敏捷流派不会暴击：暴击率按 1% → 0.5% 攻击力转换，暴击效果按 1% → 0.1% 移速转换；每轮随机使用扇形、弧线、螺旋、散射、交叉或圆环弹道，击杀精英使生命上限 +5%。
- 轮椅流派关闭射击系统；基础撞击可直接击毁普通侦察机，对精英敌机额外造成 25% 伤害，撞击 Boss 固定削减其最大生命的 2%；受到伤害减半，撞杀使生命上限 +5%，每 5 秒恢复 5% 最大生命与 5% 已损生命。按 `G` 可启动 6 秒全速冲锋，机动提升至 1.9 倍且受到伤害再降低 30%。
- 航途中会随机出现临时技能核心，可获得 12 秒歼灭超频、棱镜散射或奇点花火；精英敌机也有概率掉落。
- 击落普通敌机、精英敌机和 Boss 都会掉落星核币，奖励随关卡难度提高。
- 机库商店支持生命、火力、引擎、装甲、代币回收等有上限的永久加点。
- 敌人与 Boss 会获得玩家永久加点收益的 20%，避免后期战斗失去压力。
- 四套涂装可使用星核币购买并即时装备。

## 无限战斗

- 深空航线拥有更长的整备阶段，达到高分阈值后触发首领，击败后继续飞行。
- 首领按裂渊泰坦、镜像猎手、技能篡夺者循环出现；每位首领都有带清晰预警与安全缺口的独立弹幕，并会在后续循环进入精英形态，获得金色力场、更多生命、更快攻势和更高奖励。
- 镜像猎手复制玩家机体并强化生命；技能篡夺者会临时封锁玩家主动技能并反过来使用。
- 每次击败首领都会进入跨流派进化，可自由选取力量、敏捷、防御、吸血、吞噬与通用技能。
- “镜像僚机”会复制当前战机，以本体约 50% 的尺寸和作战性能协同开火。
- 玩家最大生命超过 1000 时，首领的每次有效攻击固定造成最大生命的 12.5%。
- 首领炼狱从基础武装开局，Boss 无限重生并强化，代币奖励快速递增。
- 侦察、拦截、强袭、压制、布雷、炮艇、轰炸和送死补给机组成八类混合敌群；所有敌机均使用独立透明 PNG 机体素材并统一以机头朝下迎战玩家。
- 强袭机使用三联扇射，压制机在脉冲封锁与追踪弹之间随机切换，布雷机制造带安全缺口的爆炸雷幕；它们的强度位于普通战机与重型炮艇之间。
- 八类敌机都可随机生成精英形态：体型、生命、攻击和奖励全面强化；精英炮艇与轰炸机继续使用随机扇形、追踪、半圆封锁攻击。
- Boss 整体生命提高 22%，攻击顺序改为随机抽取，第三阶段还会随机叠加追踪弹幕。
- 撞击普通敌机直接摧毁双方对应生命；精英仅损失 25% 生命；撞击 Boss 固定造成 75 伤害。

在 URL 后添加 `?debug=1` 可显示调试面板；战斗中按 `B` 直接进入 Boss。
