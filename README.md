# 星渊突击

《星渊突击》是一款以高速空战、流派构筑和首领对抗为核心的浏览器飞机大战。

## 背景介绍

深空航道失去回应后，守护舰队派出最后一架仍能作战的战机进入星渊。敌军、失控兵器与未知信号不断从航道深处出现，一道神秘黑影则始终潜伏在战场边缘，等待夺走每一份被击败的力量。

玩家会在持续推进中收集强化、改变战斗方式，并逐步接近信号背后的真相。普通战役不会提前公开接下来的威胁，异常回波、突然出现的敌人和战场变化需要玩家亲自发现。

## 六大流派

- 力量流派：强调正面火力、暴击成长与处决续航，适合稳定压制。

- 敏捷流派：以高速移动和散射弹幕穿梭战场，将暴击潜力转化为攻击与机动。

- 防御流派：依靠重甲、生命恢复和大口径火力稳步推进，容错率更高。

- 吸血流派：持续命中敌人即可修复舰体，擅长在高压弹幕中维持战线。

- 吞噬流派：通过连续击杀不断进化，让战机在单局内越战越强。

- 撞击流派：关闭常规机炮，以舰体冲撞和生命成长作为主要武器；`1` 为破阵冲角、`2` 为反应装甲、`3` 为堡垒姿态。

## 流派特点

六大流派在生命、移速、伤害、射速、冷却、受伤减免和体型七个维度上各有侧重，没有全能选项。

| 流派 | 优势维度 | 弱势维度 |
| --- | --- | --- |
| 力量 | 伤害、射速、生命 | 无明显短板，均衡偏攻 |
| 敏捷 | 移速、射速、冷却 | 单发伤害偏低 |
| 防御 | 生命、伤害、爆炸减免 | 射速与移速偏慢 |
| 吸血 | 全维度小幅提升 | 冷却偏长 |
| 吞噬 | 全维度小幅提升、成长性 | 冷却偏长 |
| 撞击 | 生命、伤害、极高减免 | 完全没有机炮 |

关键流派规则：

- 力量：拥有暴击，暴击击杀时回血并永久提升本局生命上限。
- 敏捷：自身不产生暴击，改为把暴击率换算成攻击力、暴击效果换算成移速。用专属技能（影步突刺、影分身、影分身子弹或万象影袭联动）击杀敌人会永久提升本局最大生命并回复生命，基础机炮不计。
- 防御：没有击杀回血，回复完全依赖专属强化「荆棘护甲」的反伤累计。
- 吸血：每次命中都按已损生命比例回血。
- 吞噬：成功吞噬按额外生命、已损生命与目标最大生命的一定比例回复；五级强化逐步提高吞噬体型、减伤与单次最大生命收益，体型成长设有明确上限。
- 撞击：关闭机炮，靠舰体冲撞作战。最大生命越高攻击力越强，每 500 最大生命提升撞击攻击，对 Boss 的撞击伤害比例较高，并周期性自动回血；生命成长不会让 Boss 撞击伤害失效。
- 所有流派的最大生命提升到一定档位后，小兵伤害会同步增强，且小兵单次伤害存在按玩家最大生命计算的下限——堆血不能无限免疫小兵。

具体倍率与全部数值请查阅开发者数值总表。

## 普通战役九战流程

普通战役先清理小兵，再自然切入 Boss。界面不会显示触发 Boss 还差多少分，也没有剧情弹窗打断操作。

1. 裂渊泰坦。
2. 第一次追逐黑影：黑影已夺走泰坦的能力，累计造成足够伤害后会向上逃逸。
3. 镜像猎手。
4. 第二次追逐黑影：强度进一步提升，逃逸门槛更高。
5. 技能篡夺者。
6. 第三次追逐黑影：三次追逐中强度最高，逃逸门槛也最高。
7. 三神共斗：三个模板同时出现，每只拥有独立的生命条，共享一个总量；哪只先打空就先炸毁，剩余 Boss 继续作战。
8. 完全体黑影：会召唤小兵；生命降到临界值时爆炸并显露原型。
9. 黑暗魔神飞机：会召唤小兵。半血时本体无敌隐退回血，由 Boss 体量的黑暗飞机接替战斗；击破本体后进入终局抉择与残党阶段。

九场战斗的强度逐场递增。完全体黑影爆炸后战场规则会发生变化，玩家的生命上限与回复效率都会被压制。

普通战役共有五段清兵航段，分别位于第一场 Boss 之前、三次黑影追逐之后，以及三 Boss 同场战之后。每段按进入航段后的累计分数自然切入下一场战斗，界面不显示任何进度或阈值。段位门槛随难度区域提升，且越往后要求越高。

## Boss 掉落安排

Boss 奖励分为两类：只能装备一个的 **V 键主动权柄**，以及可在一局内累计多个的 **专属被动强化**。每次奖励界面只能选择一项。

| 战斗 | 掉落内容 |
| --- | --- |
| 九战前三场 Boss | 击破后立刻进行主动权柄三选一，当前 Boss 本源技能必定进入候选；其专属被动核心随后被黑影夺走 |
| 黑影追逐战 | 打退黑影后掉落上一只 Boss 的专属被动三选一；被动可累计，不占 V 键，本次只取一项 |
| 三神共斗 | 三只 Boss 各有独立血量与血条，顶部共享条仅汇总剩余总量；全灭后从三项本源主动中选一项，再从三神专属被动中选一项 |
| 其他模式的 Boss | 依次进行主动权柄三选一 → 专属被动三选一 → 通用强化三选一 → 流派进化三选一 |

V 键同时只能装备一个主动 Boss 技能，新选择会替换旧主动；专属被动不会被替换。主动权柄三选一只从当前击败 Boss 自身的技能池抽取（如裂渊泰坦只会掉落泰坦池技能），不会混入其他 Boss 的技能。爽玩难度 Boss 战斗中释放的技能数量较少，普通与更高难度会释放更多技能。

五项逆航支援协议已并入通用强化池，全流派可选，不再占用独立的选择界面。原通用技能「绝对零度封锁」已移出通用池，改为 Boss 技能「绝对零度权柄」。

## 终局抉择

击破黑暗魔神后，残骸中会留下一枚损坏的黑暗核心。玩家需要在当场做出一个不可撤回的决定，随后进入终局残党阶段。

不同的决定会改变残党阶段的强度与玩家自身的状态，最终导向不同的结局。具体内容请在游戏中亲自体验。

五种终局结局全部属于黑影失败结局，但每种结局都会解锁一款符合该路线的专属涂装。Boss 专属模式完成完整九战序列后，还会额外解锁传说涂装「九渊弑神」；这项模式奖励不会改变结局仍判定失败的设定。

## 流派专属键位

G 键为各流派共用键位，但技能逻辑完全独立：力量为龙息喷火，敏捷为影步突刺，撞击为全速冲锋。防御、吸血、吞噬三流派的专属强化均为被动，不占用 G 键。

前三位 Boss 击破后即可选择主动权柄；其专属被动核心会被黑影夺走，只有击退随后出现的黑影才会生成被动强化掉落。

所有玩家使用的 V 键 Boss 技能伤害都显著低于 Boss 原版，并拥有较长的统一冷却。绝对零度会在短时间内冻结小兵、Boss 与敌方弹幕；冻结期间敌方实体的位置、运动相位、攻击计时和移动 tween 都会真正暂停，解冻后不会瞬移。

镜像 Boss 会轮换复制玩家当前流派的 G 键能力及 1/2/3 键位技能。复制力量流派时会释放更长、更宽、三股实体火焰的 Boss 龙息；单次完整命中按可承受伤害限制，满血玩家至少能承受两次。

力量流派每击杀一名敌人按额外生命上限的一定比例回复；暴击处决仍会额外提升本局最大生命，但不再按总最大生命大幅回复。

力量流派的龙息随等级提升而显著强化：长度、末端宽度、持续时间与伤害逐级成长，冷却则相应缩短。判定范围与从机头向上扩张的火焰锥完全一致。

六个流派采用不同的实体表现：力量为三层龙息与火星，敏捷为紫电切面和皮肤残影，防御为星盾与实体反刺，吸血为活体虹吸触手，吞噬为深渊巨口与獠牙，撞击为装甲冲击波、破阵箭头和撞飞碎片。

皮肤商店只展示七款成就奖励皮肤，不再出售代币换色皮肤。每款成就皮肤都是与基础战机完全不同的独立模型，并配有一枚同背景的透明专属机炮弹体：稀有使用清晰单层结构，史诗使用双层装甲与能量核心，神话增加活体核心层，传说采用黑曜、鎏金、珍珠白与一体化金龙徽记。机库会同时预览机体和子弹，实战只加载当前装备皮肤的一套素材；子弹不附加长尾迹或大范围光环，避免遮住敌方弹幕。

### 影步突刺

沿方向键（WASD 或方向键）所指方向突进，位移固定为当前等级的上限，不受鼠标位置影响。未按方向键时沿当前移动方向突进，完全静止时朝正上方。突进耗时固定，等级越高位移越远、速度越快，最高可跨越大半张地图。

突进期间完全无敌，并对整条轨迹做扫掠判定，途经的敌人全部受击而不只是终点那一个。等级提升会同时增加伤害倍率与扫掠宽度、显著缩短冷却。每命中一个敌人都回血，单次突刺的回血次数有上限；技能击杀会永久提升本局最大生命并回复生命。

### 影分身

与本体保持在同一水平线并列作战，与玩家主炮同向正上方射击，不受距离限制。

等级提升会依次增加分身数量、血量与攻击继承比例，并缩短召唤间隔；三项都达到上限后，继续升级只会进一步压缩召唤间隔。每次召唤只补充一个分身，不会一次性补满。

最低等级的分身也拥有本体最大生命 12% 的血量（万象影袭每级额外提升）；单发弹幕对分身伤害设有上限，满血分身至少能扛住 3 发（拥有融合技时扛 5 发）。分身命中敌人会附加目标最大生命一定比例的额外伤害。

## 敌军难度与突变

威胁等级决定精英与突变概率。精英与突变是两次独立掷骰：突变不要求单位先成为精英，普通小兵也可以突变，精英同样可以叠加突变。

普通区域不会出现精英与突变；困难区域开始出现精英；噩梦区域精英占多数并引入突变，同时提供最高的奖励倍率。这三个难度分别显示为：爽玩模式（无精英/突变）、普通模式（约一半精英）、地狱模式（全员精英并引入突变）。

Boss 召唤的小兵同样参与精英与突变掷骰。突变严格限制在同阶级：小兵只能取得追踪、布雷、装甲、冲刺或压制等小兵能力；所有 Boss，包括三次黑影追逐、完全体黑影与最终真身，只会借用其他 Boss 的招式。突变单位会显示对应色彩、纹章和能力提示。

## v0.7.2 更新内容

**敏捷流派 · 强化界面重构**

- 万象影袭改为独立的融合强化轨道：首次获得即拥有更高的起步等级，后续可继续升级，上限不变。
- 未获得任何基础技能前，专属强化只会给出影步突刺与影分身，万象影袭不提前出现。

- 一旦选择万象影袭，两个基础技能不再出现，后续专属升级只出融合技，构筑方向更清晰。

**撞击流派调整**

- 增强撞击流派的 Boss 战能力：撞击 Boss 的伤害比例提高，撞角基础伤害增强，主动撞击冷却缩短，冲撞更频繁。
- 重做撞杀奖励：撞毁小兵稳定获得最大生命成长，撞杀回复小幅下调以平衡收益。
- 破阵冲角（1 键）调整冷却、冲程与保护时间，并修复该技能按键无反应的问题。
- 守护战机生命值下调，略微回归平衡。

**修复**

- 修复机库商店永久能力加点的价格显示与实际扣费不一致的问题：之前按钮显示的价格偏低而实际扣费更高，代币不够的玩家点击没有反应；现在显示多少扣多少。
- 修复成就皮肤区图片在滚动前空白的问题：图片改为页面加载时立即显示，不再依赖滚动触发。

**工程优化**

- 合并多处重复计算（装甲减伤、冷却提示、生命上限增益等）为公共函数，行为不变。
- 将机体、流派、皮肤、升级、Boss、成就等静态数据从 `main.ts` 拆分到独立的 `data.ts`，代码结构更清晰。

## v0.6.5 更新内容

**终局与 Boss 掉落**

- 击破黑暗魔神后新增「损坏的黑暗核心」抉择，终局走向由玩家的选择与操作共同决定。
- 九战前三场 Boss 击破后当场选择主动权柄，专属被动则由对应黑影夺走并在追逐战后归还三选一。
- 三神共斗改为三条独立生命与独立血条，顶部共享条仅汇总显示；全灭后主动、专属被动各选择一项。
- 首领权柄的释放键位从 G 移至 V，G 键完全归流派专属主动技能。
- 修复残党阶段的清空判定：此前只检查待生成数，最后一波刚生成即被判定为清空。

**平衡调整**

- 五项逆航支援协议削弱后并入通用强化池，绝对零度改为 Boss 技能，移除独立的支援选择界面。
- 撞击流派补齐三个专属主动技能：`1` 破阵冲角、`2` 反应装甲、`3` 堡垒姿态；堡垒期间体型增大、承伤显著降低、移速下降，并强化连续台球式撞击。

**缺陷修复**

- 修复龙息喷火的方向缺陷：原实现按玩家位于屏幕左右半侧决定横喷方向，在纵向卷轴中永远无法命中敌人，且火焰完全覆盖本体，视觉上形似自爆。现改为自机头朝正上方喷射的锥形。
- 修复子弹皮肤特效残留：对象池复用子弹时未销毁上一发的光环与尾迹，紫色椭圆会永久停留在原地。
- 修复返回键在窗口缩放或宽屏下脱离游戏面板的问题。
- 影步突刺的位移改为固定使用当前等级上限，方向由方向键决定，不再读取鼠标位置。
